# HF B2C Sales Backend

This repository owns the backend and database assets for the HF B2C Sales Enquiry Automation project, including Supabase schema and migrations, RPC and function definitions, database integrity tests, backend deployment documentation, and later version-controlled n8n workflow exports.

The hosted Supabase project already exists externally. Production remains the current source of truth until a reviewed baseline is captured in this repository. No migration should be applied to any environment until that baseline process is complete.

Node.js is pinned to version `22.23.2` through `.nvmrc`.
